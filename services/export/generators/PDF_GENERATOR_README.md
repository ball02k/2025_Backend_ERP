# PDF Generator Documentation

## Overview

The PDF Generator is a comprehensive service for creating professional, print-ready PDF payment application documents for the UK construction industry. Built using PDFKit, it generates A4 documents with proper formatting, styling, and pagination.

## Features

### 1. Professional Layout
- **A4 Page Size**: Standard 595.28 x 841.89 points
- **Proper Margins**: 50 points on all sides
- **Automatic Pagination**: Content flows across multiple pages
- **Page Numbering**: "Page X of Y" on all pages
- **Watermarks**: Optional semi-transparent watermark support

### 2. Document Sections
- **Document Header**: Company info, logo, and title
- **Project Information**: Two-column layout with project and party details
- **Financial Summary**: Highlighted totals with subtotals
- **Line Items Table**: Zebra-striped rows with automatic pagination
- **Variations Section**: Detailed variation breakdown
- **Certification Section**: Green-highlighted certification details
- **Declaration & Signatures**: Formal declaration with signature lines
- **Document Footer**: Customizable footer text

### 3. UK Formatting Standards
- **Date Format**: DD/MM/YYYY (e.g., 01/12/2025)
- **Currency Format**: £1,234.56 with thousands separators
- **Negative Values**: Shown in parentheses (£1,234.56)
- **Number Formatting**: Uses en-GB locale

### 4. Professional Styling
- **Color Scheme**:
  - Primary: #1e3a5f (navy blue)
  - Secondary: #4a5568 (gray)
  - Success: #10b981 (green)
  - Highlight: #fef3c7 (light yellow)
- **Typography**: Helvetica family (Regular, Bold, Italic)
- **Table Styling**: Bordered tables with alternating row colors

## Configuration Options

### PDF Template Config

```typescript
interface PdfTemplateConfig {
  pageSize?: 'A4' | 'LETTER';           // Default: 'A4'
  orientation?: 'portrait' | 'landscape'; // Default: 'portrait'
  margins?: {                            // Default: 50 on all sides
    top: number;
    right: number;
    bottom: number;
    left: number;
  };
  currencySymbol?: string;               // Default: '£'
  footerText?: string;                   // Default: 'Generated by ERP System'
}
```

### Section Control

```typescript
sections: {
  header: boolean;         // Project and party information
  lines: boolean;          // Line items table
  variations: boolean;     // Variations section
  dayworks: boolean;       // Dayworks section (not yet implemented)
  summary: boolean;        // Financial summary
  certification: boolean;  // Certification section (if data present)
}
```

### Page 2+: Line Items
- Table with columns: #, Ref, Description, Previous, This Period, Cumulative

### Page N: Variations (if present)

### Last Page: Certification & Declaration
- Certification box (if certified)

- Signature lines for Contractor and Employer
- Document footer

## Internal Architecture

### Main Functions

#### `generatePdf()`
Main entry point that:
1. Creates PDFDocument with buffered pages
2. Calls `generatePdfContent()` to add all sections
3. Adds page numbers after content is complete
4. Optionally adds watermark
5. Returns buffer and MIME type

#### `generatePdfContent()`
Orchestrates section generation:
1. Document header
2. Project info
3. Financial summary
4. Line items (new page)
5. Variations (new page if present)
6. Certification (if present)
7. Declaration
8. Footer

### Section Generators

#### `addDocumentHeader()`
- Company logo and info
- Main title with application number
- Reference line
- Separator

#### `addProjectInfo()`
- Two-column layout
- Left: Project details
- Right: Contractor and Employer info
- Bottom border separator

#### `addFinancialSummary()`
- Itemized summary table
- Subtotals for key values
- Highlighted total row
- Proper spacing between groups

#### `addLineItemsTable()`
- Professional table header
- Zebra-striped data rows
- Automatic pagination
- Totals row with highlighting

#### `addVariationsSection()`
- Similar structure to line items
- Different column layout
- Totals row

#### `addCertificationSection()`
- Green-highlighted box
- Certified by, amount, date
- Variance notes (if present)

#### `addDeclarationSection()`
- Declaration text
- Two-column signature layout
- Signature, name, and date lines

#### `addPageNumbers()`
- Iterates through buffered pages
- Adds "Page X of Y" to bottom center

#### `addWatermark()`
- Rotates text at -45 degrees
- Semi-transparent overlay
- Centered on each page

### Utility Functions

#### `formatDate(date: Date | string): string`
Formats dates in UK format (DD/MM/YYYY):
- Handles Date objects and ISO strings
- Returns 'N/A' for invalid dates

#### `formatCurrency(amount: number, symbol: string): string`
Formats currency in UK format:
- Uses Intl.NumberFormat with en-GB locale
- Thousands separators (£1,234.56)
- Negative values in parentheses
- Customizable currency symbol

## Common Issues & Solutions

### Issue: Text Overlapping
**Cause**: Too much content in a section
**Solution**: The generator automatically handles pagination, but if you see overlapping, ensure your descriptions are reasonable length.

### Issue: Logo Not Showing
**Cause**: Invalid logo path or unsupported format
**Solution**: Use absolute path and supported formats (PNG, JPG). Check console for warnings.

### Issue: Incorrect Currency Format
**Cause**: Using wrong locale
**Solution**: The generator uses en-GB by default. For other currencies, customize the `currencySymbol` in config.

### Issue: Missing Page Numbers
**Cause**: Not using buffered pages
**Solution**: The generator enables `bufferPages: true` automatically. Don't disable this.
